# WorldCast: Distributed Multiplayer World Models

Source of the WorldCast project page.

**[Project page](https://ziyang-ye.github.io/WorldCast-Page/)** ·
**[Code](https://github.com/Ziyang-Ye/WorldCast)** ·
**[Weights](https://huggingface.co/ZiyangYe/WorldCast)** ·
**Paper** (coming soon)

WorldCast is a distributed multiplayer world model: every player runs its own client, which generates that player's
view, and the clients exchange only player state and scene state. Every video on the page is generated by WorldCast.

## Preview locally

The page is plain HTML, CSS and JavaScript: no build step, no dependencies, no third-party requests.

```bash
git clone https://github.com/Ziyang-Ye/WorldCast-Page.git && cd WorldCast-Page
npx http-server -p 8000      # or: python3 -m http.server 8000
```

Then open <http://localhost:8000/>. Use a server that answers HTTP Range requests (such as `http-server`) to seek in
the videos; Safari plays video only from such a server. `python3 -m http.server` does not support them, but is enough
for a quick look in Chrome or Firefox. Add `?motion=off` to the URL to see the reduced-motion version.

## Layout

```
index.html
assets/css/       style.css, fig3case.css
assets/js/        main.js (the page), wall.js (the opening wall), fig3case.js (the Figure 3 animation)
assets/media/     videos, stills and per-frame data, one folder per section:
                  wall, views, multiplayer, player-state, scene-state, method, gallery
assets/fonts/     Inter, Inter Tight, JetBrains Mono
assets/vendor/    LICENSES.md (third-party files)
```
